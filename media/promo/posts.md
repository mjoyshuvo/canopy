## Slack

> :deciduous_tree: **Canopy: themes for the Claude Code desktop app**
>
> I spend most of the day in the Claude desktop app's Code tab, so I made it nicer to look at. Canopy is a free plugin with 6 themes:
>
> • **Firefly Lake** – moonlit lake, fireflies, slow-moving trees (animated, dark)
> • **Silver grass** – grass meadow at dusk with a breeze rolling through (animated, dark)
> • **Apple green** – soft light theme, no motion
> • **One Dark Pro**, **Dracula**, **Material** – the VS Code favourites
>
> Install from any Code tab session:
> ```
> /plugin marketplace add mjoyshuvo/canopy-claude-desktop-theme
> /plugin install canopy@canopy
> ```
> Then start a new session. A picker opens the first time; `/canopy pick` brings it back.
>
> Repo: https://github.com/mjoyshuvo/canopy-claude-desktop-theme
> Feedback and theme ideas welcome. Stars help too :star:
